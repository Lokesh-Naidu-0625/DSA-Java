# Core Java for DSA

This section contains the **Java fundamentals and built-in data structures** that are commonly used when solving DSA problems.

The purpose of this section is to become comfortable with Java syntax, APIs, and collections before applying them to algorithmic problems.

## 🎯 Goal

The goal is to make Java syntax and commonly used data structures **second nature**, so that during problem solving I can focus on the algorithm instead of struggling with Java syntax.
