Patterns and Algorithms

This section contains the most important DSA problem-solving patterns and algorithms.

The goal is to learn how to recognize the structure of a problem and select an appropriate approach.

# 1. ARRAYS

Arrays are probably the **most important DSA category for interviews**.

### Core patterns

```
Arrays
│
├── Basic Traversal
├── Sorting
├── Two Pointers
├── Sliding Window
├── Prefix Sum
├── Difference Array
├── Hashing
├── Kadane's Algorithm
├── Binary Search
├── Merge-based techniques
└── Matrix
```

### Two Pointers

Several patterns exist:

```
Two Pointers
│
├── Opposite Direction
│   └── left ← → right
│
├── Same Direction
│   └── slow → fast
│
├── Fast / Slow
│
└── Partitioning
```

Typical problems:

```
Two Sum II
3Sum
Container With Most Water
Remove Duplicates
Move Zeroes
Sort Colors
```

```
Greedy

├── Jump Game
├── Gas Station
├── Job Scheduling
```
